# 🎥 YT Nexus - YouTube Thumbnail Downloader

🚀 **Live Demo:** [Click Here to Use YT Nexus](https://yt-thumbnaildownload.netlify.app/)

## 🌟 About The Project
YT Nexus is a premium, fast, and free utility tool to download high-definition (HD, 4K) YouTube video thumbnails instantly. Designed with a sleek Dark Glassmorphism UI for creators and developers.

## ✨ Features
- **One-Click Download:** Extracts the maximum resolution image directly from YouTube servers.
- **100% Free & Unlimited:** No daily limits or hidden charges.
- **Premium UI:** Smooth animations, dark mode, and responsive design.
- **Monetized:** Integrated with Adsterra banner and popunder ads.

## 💻 Tech Stack
- **Frontend:** React.js (Vite), Tailwind CSS
- **Deployment:** Netlify
